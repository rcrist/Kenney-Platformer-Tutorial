Python Arcade includes many built-in resources, including [Kenney](kenney.nl) Toon characters, tilemaps, sound effects, music, and more. But wait—what if we want to go beyond the built-in resources?

We may want to use assets from the vast Kenney libraries, itch.io, OpenGameArt, AI-generated pixel art, or artwork we create ourselves. We may also want to build our own levels with the [Tiled tilemap editor](www.mapeditor.org), add enemies and NPCs, place background and foreground objects, and create our own animated sprites. What happens when the player perishes in a fierce battle—or simply falls off a cliff? How do we restart the level or the game?

And that is only the beginning. How do we handle player inventory and advancement? How do we create facial animations or give characters new abilities? What about particles, shaders, lighting effects, sound effects, background music, and parallax backgrounds? How do we create a heads-up display (HUD) that provides a polished user interface for the game?

In this section, we will explore how these pieces fit together to turn a basic Python Arcade project into a complete 2D platformer game.
