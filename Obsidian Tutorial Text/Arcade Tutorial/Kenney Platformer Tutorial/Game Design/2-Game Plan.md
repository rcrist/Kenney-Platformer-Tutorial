Before we launch into a lot of code development, level design, and player development, we should step back and decide what the Game Plan is for this game. For example, in Nintendo Super Mario Brothers, Mario's goal was to rescue princess Peaches. He had to complete all of the challenges along the way.

It is good to define the game objective(s) before starting the game development so we know when we are done!
- Define the game type and player goals
- Define the approximate number of levels
- Select game assets and development tools
- We will add "juice" to the game but after we get the core game up and running

## Game Plan
---
Game Type: 2D Platformer
Game Library: Python Arcade
Name: Kenney Platformer Tutorial

Game Objective:
For this tutorial, I like the idea of creating a Super Kenney Bros game. The male adventurer's goal is to rescue the female adventurer from the clutches of the evil Robowser (Robot Cartoon Character).

Game Levels:
1 world x 4 levels = 4 levels (SMB has 32 levels divided into 8 worlds of 4 levels each)

Game Features:
- Leaves in the wind
- Dark levels with player illumination
- Moving grass in the wind
- No score or health per se, player accumulates new abilities
- Enemies increase in strength and number on each level
- Level bosses
